# Self-Hosted Web Fonts

The Bernhardt Lab website self-hosts variable WOFF2 subsets from Fontsource packages for stable rendering without a Google Fonts runtime request.

- Manrope: `@fontsource-variable/manrope` 5.2.8, licensed under the SIL Open Font License 1.1.
- Fraunces: `@fontsource-variable/fraunces` 5.2.9, licensed under the SIL Open Font License 1.1.

The upstream license files are included in the corresponding Fontsource packages.
