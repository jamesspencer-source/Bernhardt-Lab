# Envelope Escape Art Direction

## Target

Envelope Escape V2 should read as a professional browser arcade game set inside a stylized bacterial envelope stress assay. The look is dark, luminous, and scientific: microscope chamber, membrane bands, peptidoglycan mesh, fluorescent molecular modules, phage adsorption, beta-lactam shock fronts, autolysin cracks, and lysis storms.

The game should not look like generic circles collecting generic coins. Every sprite should suggest cell-envelope biology at small scale.

## Shipped Production-Track Asset Pack

The current production-track pack is generated by:

```sh
python3 scripts/generate_envelope_escape_assets.py
```

It writes deterministic PNG assets and preview sheets under `assets/game/envelope-escape/`:

- `cells/`: ten-frame species sheets at 64x64 per frame.
- `phages/`: phage flight and attachment sheets at 64x64 per frame.
- `hazards/`: beta-lactam shock, autolysin crack, osmotic rupture, and lysis storm sheets.
- `pickups/`: `PG synthase`, `Lipid II`, and `Hydrolase restraint` sheets at 48x48 per frame.
- `fx/`: chamber background, fluorescent particle, and response flare sheets.
- `ui/`: response icons and run-report badges.
- `audio/`: notes for future sound assets; the current V2 uses generated Web Audio tones or silence.
- `previews/`: contact sheets for quick QA before runtime integration.

## Artist Or Generation Brief

Use this prompt for a future artist/generation subagent pass:

> Create production-ready 2D sprite sheets for a dark premium scientific arcade game called Envelope Escape: Stress Test Chamber. The player is a bacterium surviving phage adsorption, beta-lactam shock fronts, autolysin cracks, osmotic rupture zones, and lysis storms inside a microscope-like bacterial envelope assay. Style: luminous microscopy-inspired arcade sprites, transparent background, crisp at 64x64 and 48x48 game scale, biologically specific silhouettes, no labels, no scenery, no poster composition. Preserve a dark navy/cyan/teal base palette with restrained warm amber/crimson danger accents. Produce whole strips at once so frame-to-frame proportions stay stable.

Required sheets:

- Seven cell sheets, one per species: `ecoli`, `paeruginosa`, `saureus`, `spneumoniae`, `cglutamicum`, `kpneumoniae`, `abaumannii`.
- Each cell sheet: 10 frames, 64x64 per frame, transparent background. Frames 0-3 idle/swim, 4-5 hurt/stress, 6-9 lysis breakup.
- Phage flight sheet: 6 frames, 64x64, recognizable head, tail, baseplate/fibers.
- Phage attach sheet: 4 frames, 64x64, adsorption/attachment cue.
- Pickup sheets: `PG synthase`, `Lipid II`, `Hydrolase restraint`, 4 frames each, 48x48.
- Hazard sheets: beta-lactam shock 96x96 frames, autolysin crack 128x64 frames, osmotic rupture 128x128 frames, lysis storm 128x128 frames.
- FX sheets: fluorescent particle 32x32, response flare 128x128.
- UI icons: Patch Wall, Purge Phages, Boost Motility, 64x64.

Quality gates:

- Transparent background.
- Stable anchor and silhouette across each strip.
- Reads clearly at 1x game scale.
- Species silhouettes are distinct.
- Hazards are visually distinguishable before impact.
- Danger accents are readable without overwhelming the dark chamber palette.

## Normalization Rules

Frame sizes are fixed by the Phaser asset manifest in `game-src/envelope-escape/src/assets.ts`.

- Cells and phages: 64x64 frames.
- Pickups: 48x48 frames.
- Shock fronts: 96x96 frames.
- Cracks: 128x64 frames.
- Ruptures, storms, and response flare: 128x128 frames.
- UI badges and response icons: 64x64 frames.

If a future asset pass produces larger raw sheets, normalize them back to these exact frame sizes before updating the manifest or renderer. Keep one shared scale per strip and keep the first frame aligned to the same center anchor.

## Launch Gate

Do not make Phaser V2 the default footer game until:

- The custom sprite-sheet pack is integrated.
- V2 passes desktop, tablet, and phone smoke tests.
- `python3 scripts/check_leaderboard_worker.py` passes against the live Cloudflare worker.
- V1 remains available via `?envelopeLegacy=1` or automatic fallback.
