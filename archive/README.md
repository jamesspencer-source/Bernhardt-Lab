# Archive

This folder is for retained historical material that is not part of the live Bernhardt Lab website build.

- `legacy-imports/tmp/` contains Squarespace-era import scratch files, extracted presentation contents, one-off crop tests, and source-capture artifacts previously stored under root-level `tmp/`.
- `legacy-imports/replaced-profile-images/` preserves large imported profile-image originals that were replaced with web-optimized JPEGs.

Do not link to files in this folder from public pages. `scripts/build_site.py` excludes `archive/` from public HTML validation and flat-site route generation.
